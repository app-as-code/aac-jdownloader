# Icon source

The icon is downloaded from the dashboard-icons collection (repository `homarr-labs/dashboard-icons`,
served via jsdelivr). No icon was drawn or modified by hand, apart from the resizing described below.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.png` | `png/jdownloader.png` (497 x 503 px) | Default icon, scaled to 256 x 256 px |

Download URL:

- https://cdn.jsdelivr.net/gh/homarr-labs/dashboard-icons/png/jdownloader.png

Processing: the upstream PNG was downscaled to 256 x 256 px to stay within the size budget
(the upstream SVG is about 330 KB, so it was not used). The aspect ratio changed by about 1 %.

No separate dark or light variant is available in the collection, so the same icon is used in both themes.

rights remain with the upstream project; the icon is used only to identify the application.
